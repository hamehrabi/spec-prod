# Attribution

The blueprint library here is an **original implementation of a published method**, not a
reproduction of it.

## What this is

The method -- the ten-step spec-driven workflow, the stage ordering, and the discipline of
writing specifications before code -- comes from **_Spec-Driven AI Engineering_ by Gem Iroko**.

Eight blueprints draw additionally on: Richards & Ford, *Fundamentals of Software
Architecture*; Ousterhout, *A Philosophy of Software Design*; Khononov, *Learning
Domain-Driven Design*; Hohpe, *The Software Architect Elevator*; *Software Architecture: The
Hard Parts*; and the Gang of Four pattern catalogue.

## What this is not

**No text is copied from any of them.** They are not included in this repository and are not
redistributable -- see `.gitignore`.

The templates, prose, worked examples and structure in `spec-driven-template/` are original
work, written to apply the method rather than to restate it.

## If you wrote one of those books

The intent is to credit the source of the ideas plainly and send readers to the original. If
anything here reads as more than that, say so and it will be changed.
