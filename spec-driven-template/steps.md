# The Complete Spec-Driven AI Engineering Workflow

The workflow used throughout this book is simple enough for beginners and structured enough for serious software work. You will use it repeatedly until it becomes natural.

1. **Capture the idea:** Write the rough product or feature idea in plain language.
2. **Define requirements:** Convert the idea into specific behavior, rules, constraints, and acceptance criteria.
3. **Write the product specification:** Clarify the user flow, feature scope, out-of-scope items, and success conditions.
4. **Write the technical specification:** Define the architecture, data, APIs, validation, security, and error handling.
5. **Create tasks:** Break the work into small, ordered, testable units.
6. **Plan tests:** Write the checks that prove each requirement is satisfied.
7. **Generate or write code:** Implement one task at a time using the specification and test plan as context.
8. **Review the result:** Compare the implementation against the requirements, specification, and tests.
9. **Prepare for deployment:** Check configuration, errors, logging, rollback procedures, and production readiness.
10. **Maintain the specification:** Update the documentation whenever decisions or behavior change.
